# Contributing to eqc-kit

Thank you for your interest in contributing to eqc-kit.

## Key Principles

- **Zero runtime dependencies** — a hard rule. The engine is vendored into user repos; adding a dependency breaks this contract.
- **Node >=18 only** — do not introduce features requiring a newer version.
- **Harness-agnostic prompts** — Prompts must never name a specific AI tool, model, or framework hook. They are playbooks any agent can follow.
- **No company-internal names** — all code and documentation uses generic terminology. No references to internal tools, standards, or organizational details.
- **Managed files carry markers** — Files generated by the Installer include a marker comment (e.g., `<!-- eqc-kit: do not edit -->`) so users can safely regenerate them.

## Getting Started

1. Clone the repository.
2. Install Node >=18.
3. Run `npm test` to verify the test suite passes.
4. Make your changes.
5. Run `npm test` again to ensure nothing broke.
6. Submit a pull request.

## What to Avoid

- Do not add dependencies to `package.json`.
- Do not use Node features below 18.
- Do not reference AI-specific features, commands, or hooks in prompts.
- Do not include company names, internal acronyms, or proprietary terms.
